START circle variants

Idle: one big amber circle is the START button (300 dp). Running: the same spot becomes the pulsing beat indicator, a smaller outlined STOP sits under it, and the CPR elapsed time with the START clock time sits under STOP. Rate buttons and the countdown do not move, so hands know where everything is.
